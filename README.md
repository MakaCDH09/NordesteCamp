# 🏆 Nordeste Camp

Este projeto é um site desenvolvido como **trabalho acadêmico**, focado na criação de uma plataforma para organização e divulgação de campeonatos de eSports (FPS e Fighting Games) no Nordeste brasileiro.

---

## 📌 Sobre o Projeto

O **Nordeste Camp** tem como objetivo oferecer uma interface moderna, responsiva e intuitiva para que jogadores e espectadores acompanhem informações sobre modalidades, regulamentos, classificações e canais de contato dos torneios.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica das páginas.
* **Tailwind CSS**: Estilização responsiva, componentes com efeito *glassmorphism* e paleta de cores personalizada.
* **JavaScript**: Interatividade e dinamismo do projeto.
* **Docker**: Containerização do ambiente de desenvolvimento/servidor web.

---
